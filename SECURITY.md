# Política de segurança

## Como relatar uma vulnerabilidade

Não abra issue pública. Use o recurso **Report a vulnerability** na aba **Security** deste repositório (relato privado do GitHub).

Inclua: o que encontrou, como reproduzir e o impacto esperado. Respondemos em até 5 dias úteis.

## Escopo

- Código deste repositório (API, worker de coleta, app).
- Exposição de dados pessoais (CPF, dados de usuários, dados de doadores).

## Fora do escopo

- As fontes oficiais de dados (Câmara, Senado, TSE, Portal da Transparência). Problemas nelas devem ser relatados a cada órgão.
