# Vida Pública

App para acompanhar o que políticos, candidatos e partidos fazem, a partir de dados públicos oficiais: votações, propostas, presença, gastos e o caminho do dinheiro de campanha. Cada informação traz a fonte oficial e a data.

> Em desenvolvimento. Veja o [roadmap](docs/roadmap.md).

## Princípios

- **Fonte em tudo:** nenhum número aparece sem a fonte oficial e a data.
- **Apartidário:** sem nota, sem ranking, sem recomendação de voto. A mesma regra vale para todos.
- **Dado ausente não é zero:** o que não foi publicado aparece como "não disponível".
